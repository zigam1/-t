# Smart Pedestrian Signal | إشارة المشاة الذكية

موقع تعريفي تفاعلي: مجسم 3D (Three.js) + محاكاة تشغيل مستقلة، عربي/إنجليزي، جاهز للنشر على Vercel.

## التشغيل
```bash
npm install
npm run dev      # للتجربة محليًا
npm run build    # للبناء (المخرجات في dist)
```

## النشر على Vercel
1. ارفع المجلد إلى GitHub.
2. من Vercel: Add New → Project → اختر المستودع. سيتعرف على Vite تلقائيًا (Build: `npm run build`، Output: `dist`).

## كيف تعدّل المحتوى (كل شيء في `src/data/`)
| الملف | ما تعدّله |
|---|---|
| `content.js` | النصوص، النسختان، المقارنة، المراحل، **النتائج**، الاستخدامات، المعرض، **التواصل** |
| `components.js` | اسم ووظيفة كل قطعة |
| `simulation.js` | أزمنة المحاكاة، حد تحذير V2، **أرقام الدبابيس** |
| `ui.js` | نصوص الواجهة |

- **أضف صورة/فيديو:** ضعه في `public/images` أو `public/videos` ثم أضف سطرًا في `content.gallery`.
- **أضف نتائج التجارب:** املأ `content.results.items`. القسم يعرض رسالة «لا نتائج» ما دام فارغًا ولا يخترع أي أرقام.
- **أرقام الدبابيس:** في `simulation.pins`، وستظهر تلقائيًا في بطاقة كل نسخة.
- **معلومات التواصل:** `content.contact` (القيمة `null` تعرض «سيُضاف لاحقًا»).

## ملاحظات صدق مهمة
- أزمنة المحاكاة (أصفر 3 ث، عبور 8 ث، حد 30 سم) **قيم افتراضية للعرض** وليست من الاختراع. عدّلها من `simulation.js`.
- توصيل الأسلاك وألوان حلقات المقاومات في المجسم **توضيحية** حتى تتوفر الأرقام الفعلية.
- شرط التحذير في V2 (مركبة أقرب من الحد أثناء أخضر المشاة) مبني على وصف المشروع، ويُضبط من `simulation.v2`.
- المجسمات تُبنى برمجيًا في `src/three/parts.js`. لاستبدال أي قطعة بنموذج GLB حقيقي عدّل دالتها هناك.


## نشر الموقع على GitHub Pages (مهم)

هذا المشروع يستخدم Vite وملفات JavaScript/CSS modules؛ لذلك لا تنشر ملفات المصدر مباشرة من خيار Deploy from a branch. يجب استخدام GitHub Actions لبناء الموقع أولاً.

1. ارفع محتويات هذا المجلد إلى جذر المستودع (بحيث يكون `package.json` و`index.html` في الصفحة الرئيسية للمستودع).
2. افتح Settings → Pages.
3. من Build and deployment اختر GitHub Actions.
4. افتح تبويب Actions وانتظر انتهاء مهمة Deploy to GitHub Pages بنجاح.
5. افتح رابط Pages بعد اكتمال النشر. عند كل تحديث للملفات سيعاد النشر تلقائياً.

لا تختَر Deploy from a branch؛ لأن ذلك يعرض صفحة HTML دون تشغيل بناء Vite، وقد تظهر أزرار V1 وV2 فقط دون التصميم والتفاعلات.
